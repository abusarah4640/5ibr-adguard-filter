# 5ibr v2.2.0 — Future Professional Edition

## Summary

This release evolves the established 5ibr interface into an enterprise cyber-intelligence console while preserving the v2.1.0-stage2 operational, authentication, localization, and readiness contracts.

## Visual system

- A new future-facing Bootstrap layer adds cyber accents, glass-like navigation, premium panel depth, status rings, CSS circular gauges, restrained motion, and a substantially refined dark theme.
- The header now exposes version, user, theme, language, notifications, and live status context.
- The footer exposes runtime version, commit identifier, environment, and product identity.
- Logical CSS properties and responsive breakpoints preserve RTL and mobile behavior.
- Reduced-motion preferences are honored.

## Operational UX

- Dashboard: executive summary with confidence/readiness gauges and the existing health, activity, intelligence, database, suggestions, actions, and readiness data.
- Analyzer: concise decision/result panels followed by an explicit raw-report disclosure.
- Review Queue: upgraded workbench styling around existing expandable evidence, policies, confidence, and decision forms.
- Audit: client-side advanced search, result filtering, CSV export, and sortable column controls. Server routes and persisted audit data are unchanged.
- Markdown reports: copy, download, print, fullscreen, line gutter, and scrollable viewer controls.
- Notifications and loading: existing Bootstrap toasts gain the new visual system; loading buttons and shimmer/skeleton primitives remain dependency-free.

## Security and compatibility

Flask-Login, Remember Me, CSRF synchronizer tokens, logout, session protection, secure cookies, RBAC, and fail-closed authorization remain intact. No API, database schema, analyzer logic, readiness logic, CLI command, or frontend dependency was changed.

## Runtime metadata

The runtime version is `2.2.0`. Deployments may set `FIVEBR_ENV` and `FIVEBR_COMMIT` to expose precise footer metadata; safe local defaults are used otherwise.
